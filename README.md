# Electricity Tariff Research — Supplementary Archive

Supplement to the manuscript **"The Volatility Penalty in Progressive Electricity Tariffs: Sharp Finite-Sample Bounds and Constrained Tariff Design"** (A. Jalan; working submission version of 24 October 2026).

## What is here

| Folder | Contents |
|---|---|
| `01_Mathematical_Proofs/` | Full proofs (PDF + LaTeX source), notation |
| `02_Data_Documentation/` | Source dataset provenance, download instructions, cleaning protocol, tariff sources |
| `03_Source_Code/` | Python implementation (tariffs, theory, data pipeline, optimisation, figures, tables) |
| `04_Tests/` | 26 pytest tests (all passing at build time) |
| `05_Computational_Results/` | `synthetic/` results used in the manuscript; `observed/` is EMPTY (see below); execution log |
| `06_Figure_Sources/` | Figure 1 and Figures S1–S5 (PDF, EPS, 600-dpi TIFF, PNG) |
| `07_Additional_Tables/` | Tables S1–S9 (xlsx) |
| `08_Research_Audit/` | Literature matrix, novelty assessment, mathematical audit, data limitations, decision log, verification report |
| `09_Reproduction_Guide/` | Step-by-step reproduction, expected outputs, environment, status |

## The most important limitation

**No observed household data were analysed.** The CEEW Mathura/Bareilly smart-meter dataset (doi:10.7910/DVN/GOCHJH) could not be downloaded from the build environment (network policy blocked Harvard Dataverse). Every number in the manuscript comes from a **synthetic** panel generated by `03_Source_Code/simulations.py`. The observed-data pipeline (`data_ingest.py`, `cleaning.py`, `build_panel.py`, `observed.py`) is implemented and unit-tested on synthetic files only.

## Quick start

```bash
pip install -r requirements.txt
python 03_Source_Code/run_all.py        # ~1 minute; regenerates synthetic results, figures, tables, validation, tests
```
